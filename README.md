### 🚀 DEPLOYMENT PROTOCOL (NETLIFY)

To host this terminal globally with automated CI/CD:

1. **Repository Setup**:
   - Initialize a Git repository in your project root.
   - Push all files to a private/public GitHub repository.

2. **Netlify Configuration**:
   - Log in to [Netlify](https://app.netlify.com/).
   - Select **"Add new site"** > **"Import an existing project from GitHub"**.
   - Choose your repository.

3. **Build Settings**:
   - **Build Command**: Leave empty (No-Build ESM Architecture).
   - **Publish Directory**: `.` (Current root).

4. **Environment Variables**:
   - Navigate to **Site Settings** > **Environment variables**.
   - Add `API_KEY`: Paste your Google Gemini API Key.
   - *This key is required for Yusra and Ideas Lab to function.*

### 📱 LOCAL EXECUTION (TERMUX)

Designed for sovereign local hosting on Android devices.

1. **Environment Setup**:
   ```bash
   pkg update && pkg upgrade
   pkg install nodejs
   ```

2. **Server Execution**:
   ```bash
   # Navigate to the project directory
   npx serve -s .
   ```

3. **Access**:
   Open your browser to `http://localhost:3000`.
